Return & Exchange Policy

We aim to ensure a smooth and transparent shopping experience. Please read our policies carefully before placing a request.

Exchange Policy

Products can be exchanged once delivered for a different size or color at no extra charge.

How to Request an Exchange

You can request an exchange directly from your account: Homepage → Profile → My Orders → Select Product → Request Exchange

  • Exchange request must be raised within 7 days of delivery
  • No need to email or call support for exchange requests
  • Admin will review and either approve or reject the request
  • Request status will be visible in the My Orders section

Once approved, the replacement product will be delivered within 10–12 days. Please keep the original tag and invoice intact for a smooth process.

Return & Refund Policy

Returns can be requested through the same process as exchange: My Orders → Select Product → Request Return

  • Customer must provide a valid reason for return
  • A ₹100 delivery charge is non-refundable
  • Request will be reviewed by admin for approval or rejection
  • Status will be visible in the My Orders section

If approved, the product will be picked up within 10–12 days. Refund will be processed after quality check, provided the product is returned in its original condition.

If a return request is rejected, you may contact support at gracestyledesign@gmail.com or call us for further assistance.

Order Cancellation Policy

Order cancellations are generally not allowed once placed. If cancellation is required, you must contact support immediately for assistance.
